# Security

The canonical security policy and audit record for this repo lives at
[`docs/SECURITY.md`](docs/SECURITY.md). GitHub's "Security" tab on
this repo discovers that file via this top-level redirect.

To report a vulnerability, please follow the "Reporting a vulnerability"
section at the top of `docs/SECURITY.md` — **do not** open a public
GitHub issue for an unfixed vulnerability.
